A continuacion se dara el paso a paso para poder ejecutar el archivo .sql en DBeaver

1- Tener instalado Git en tu computadora.

2- Ir al directorio donde quieras copiar el archivo del repositorio,
hacer click derecho y clickear la opcion Open Git Bash Here.

3- Escribir el comando git clone https://github.com/Ivan-Castagnola-GH/Entregas_Coderhouse.git

4- Verificar que los archivos se clonaron en el directorio seleccionado.

5- Abrir el archivo con DBeaver.
